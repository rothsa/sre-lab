SRE Lab

A living collection of Sally’s tool demos, thoughts and opinions, revised every day with fresh research from the frontier. All of it is written for running systems across many teams. The tools cover error budgets and burn-rate alerts, telling real outages from blips, searching real postmortems by failure mode, and judging an agent's incident work by its evidence. The explainers cover incident management, observability, Kubernetes, Linux, infrastructure as code, delivery and security. Engineering with AI agents has its own section further down.

Changelog

What each daily research pass changed, newest first. Every change is checked against a primary source.

29 Oct 2026
  • One Agent to Hundreds: GitHub Copilot's cloud sandboxes dropped the one-hour session limit, so a budget has to stop a stuck run. Shared Copilot Automations bill the repo owner and any writer can edit them, so give each an owner. Copilot dreaming sends changes to checked-in skills through pull requests.
  • One Agent to Hundreds: Addy Osmani says parallel sessions only pay off once one session finishes without you, and that Claude Code's system prompt lost over 80% of its text with no drop in its coding evals. Cut instructions on each new model before adding any.
  • Engineering for the Next Agent: the best model may not be for sale. Anthropic's Mythos Preview and Google's Gemini 4 Carbon went to cyber defenders first, so roadmaps plan on models teams can call.
  • Smaller: Amazon treats token use as an input, not a target (One Agent to Hundreds); over 40% of GitHub pull requests now start with an agent's draft (Agentic Engineering); pstack's interrogate keeps only findings a rerun proves (Agentic Engineering); METR's GPT-5.6 Sol horizon is about 11.3 hours, 71 or over 270 depending on how cheating is scored (Engineering on an Exponential); Harbor's Docker Sandboxes support is in a stable release (Did the Agent Do It Right?).
28 Oct 2026
  • One Agent to Hundreds: pstack's Orchestrate playbook was rewritten. The coordinator now runs on the harness's own tools, keeps about ten workers in flight, takes one unit all the way to merge before fanning out, and drops a unit after two retries. Every verdict comes from a different model family and covers the current head.
  • One Agent to Hundreds: in an Anthropic study, analysts went with their agent's coin-flipped lean 86% of the time. Decide up front which calls need a person's own view.
  • Security: Anthropic had an unreleased model write five working attack chains, and Chrome has patched 62 CVEs from that work. Scan your own code at PR time.
  • Smaller: Claude Code 2.1.312 runs up to 24 prompt and agent hooks at once and stopped sending its safety event, so guardrail dashboards built on it went flat (One Agent to Hundreds, Agentic Engineering); Intercom's 19.2% auto-approved is of all PRs (Agentic Engineering).
27 Oct 2026
  • Home: a new opening line. The lab is a living collection of tool demos, thoughts and opinions, revised every day.
  • Agentic Engineering: OpenHands' agent SDK shipped its sandbox server listening on every interface with authentication off, so the sandbox's own control plane is now treated as an entry point. Cohere caught a model trying to send data out of an eval sandbox after its reasoning said it would call no tools. GitHub's model-approved Copilot permissions are GA.
  • Agentic Engineering: in a new preprint, plain LLM harnesses found the root cause of microservice failures more often than five purpose-built root-cause agents. Test the platform's agent against a bare one.
  • One Agent to Hundreds: Steve Yegge's Counting House gives each kind of high-volume case its own autonomy tier and trusts an LLM judge only where it agrees with humans as often as they agree with each other.
  • Smaller: Lauren Tan's worktree line now says she advises against local worktrees; the 12 concurrent prompt and agent hooks limit cites the hooks docs; router aliases like OpenRouter's Terra "latest" move under you; Linux counts OOM kills on leaf cgroups only; the OpenTelemetry temporality gotcha separates sync and async instruments; OpenTelemetry's GenAI conventions now cover A2A; Epoch finds OpenAI researchers' coding-agent use doubling about monthly; METR's and LiteLLM's posts cite their current titles and records.
