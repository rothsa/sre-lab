Changelog

What each daily research pass changed, newest first. Every change is checked against its source, primary where one exists.

22 Nov 2026
  • 💣 Security: inference providers have now confirmed that prompts leaked. Phala (10 Nov) says to treat one model's requests from 21 Oct to 8 Nov as exposed, after an attacker took over an inference VM. Together (21 Nov) says an outsider downloaded stored prompt samples after an AI coding agent committed a credential to a public repo. OpenRouter (22 Nov) dropped three providers and took 125 endpoints off its zero data retention list. Rotate any secret that went into a prompt on those routes, and test a retention flag before you count it as a control.
  • One Agent to Hundreds: permitting an agent harness doesn't put it under your policy. VS Code 1.147 (18 Nov) lets admins permit the Claude and Codex harnesses next to managed Copilot settings, and says those sessions run without Copilot's managed permission, sandbox, MCP and plugin controls. GitHub (16 Nov) adds that selecting the Copilot harness doesn't turn sandboxing on (Agentic Engineering). For each tool, find the client that skips the policy.
  • Engineering for the Next Agent: an offline eval gain needs an online check before it decides a release. Spotify (19 Nov) pairs offline evals with A/B tests. At Meta (Sep) a raw offline score got the direction wrong in 31 of 113 comparisons.
  • Engineering on an Exponential: the 16-hour limit belongs to the older suite on METR's tracker. METR's 20 Nov update adds tasks up to 200 hours, but human baselines back only 9% of its task-length estimates, so the long end of the curve is still weakly measured.
  • Smaller: at Uber a valid token is not enough, a runtime check can deny an action outside the agent's defined intent (Agentic Engineering); Claude Code's npm stable tag is now 2.1.323, still without the Bash allow rule fix (Agentic Engineering); Lauren Tan's team also uses Lean and property-based UI tests (One Agent to Hundreds); pstack quotes are checked against 0.15.46 (One Agent to Hundreds); Pulumi Neo's read-only mode blocks Pulumi Cloud writes but not connected tools' credentials (Infrastructure as Code); moved links for the Codex changelog, Pulumi docs and two OpenAI alignment posts.
21 Nov 2026
  • Security: attackers now point agents at a target and let them find the bug. AWS (20 Nov) watched an actor's agents, told only to "obtain shell access", find a zero-day in an open-source application and go from mapping its API to writing files on the server in about 11 minutes. Labs and researchers showed this through October and November. Now it is in an intrusion.
  • One Agent to Hundreds: more agents pay off only where something outside the agents can check the work. METR (20 Nov) found swarms beat the best of several independent runs only on tasks with a clear metric, and large swarms did worse when they had to make up their own. ProgramBench and Vals AI had already measured the extra cost.
  • One Agent to Hundreds: agents are moving off the laptop, and vendors now ship the plumbing. Codex CLI 0.171.0 (20 Nov) runs noninteractive sessions on a remote app server, and Kiro (19 Nov) connects cloud sessions to a customer's VPC. Where agents run becomes the platform and network teams' call.
  • Security: a password reset doesn't remove what the attacker added. In Google's COLD RELIC case (17 Nov) the attacker's passkeys survived password and session resets. Account-takeover playbooks need a step that removes added sign-in methods.
  • Smaller: CISA's exploited list is at 1,790 and now includes the vCenter bug, with three days to fix (Security); GPT-6.2 Astra's ARC-AGI-3 scores, 100% with a provider harness and 70.3% with the standard one, join the harness line (One Agent to Hundreds); Claude Code 2.1.330 narrows what a name entry in deniedMcpServers blocks, so deny by URL (One Agent to Hundreds); METR's 20 Nov update finds task horizons doubling about every 110 days with harder tasks added (Engineering on an Exponential, Engineering for the Next Agent).
20 Nov 2026
  • 💣 Security: patch vCenter this week. Broadcom fixed CVE-2026-123890 on 19 Nov, a vCenter login bypass with no workaround. Google says a suspected PRC-nexus group had exploited it since early September, reaching vCenter from a BeyondTrust appliance it already held. Keep management consoles off the internet, and limit who can reach them from inside too.
  • Security: the inference path leaks secrets. Dragos (19 Nov) sent about two million prompts carrying canary AWS keys to AI services and found at least three providers breached without knowing it, marketplace resellers keeping prompts, and zero data retention flags often ignored. Keep credentials out of agent context, and pin which providers a router may use.
  • One Agent to Hundreds: more tools ship a coordinating agent, and people still read the threads. Kiro Crew 0.13 (19 Nov) put its conductor in every standard build. Thorsten Ball (19 Nov) says Amp users who treated the main agent as a chief of staff were disappointed, because you still have to go in and review.
  • Agentic Engineering: know what a broken guard does. In Claude Code 2.1.329 (19 Nov) a hook that errors lets the call through, in Code Mode too, unless it sets onFailure: "block". Since 2.1.328 a command that a hook rewrites to a sandbox-excluded one runs outside the sandbox.
  • Smaller: OpenAI's approval rule for model gateways is in effect from 20 Nov (One Agent to Hundreds); the Dex Horthy review line names the No AI Slop manifesto he launched (One Agent to Hundreds); a Claude Code source for OSC 7501 (One Agent to Hundreds); Copilot approvals generally available since 28 Oct (Ownership); the ubuntu-latest move to 26.04 was due to finish on 19 Nov (Delivery).
