SRE Lab

A living collection of Sally’s tool demos, thoughts and opinions, revised every day with fresh research from the frontier. All of it is written for running systems across many teams. The tools cover error budgets and burn-rate alerts, telling real outages from blips, searching real postmortems by failure mode, and judging an agent's incident work by its evidence. The explainers cover incident management, observability and cardinality, Kubernetes, Linux, delivery, infrastructure as code and Terraform, security, and code and service ownership. Engineering with AI agents has its own section further down.

Changelog

What each daily research pass changed, newest first. Every change is checked against its source, primary where one exists.

12 Nov 2026
  • Security: rotating secrets doesn't evict an attacker who changed who is trusted. The wfx-loot stealer ran in GitHub Actions on stolen developer tokens (from 10 Nov), with 4,837 compromised accounts probing 61,764 repositories by Aikido's count. It opened AWS role trust policies to any account and added Azure federated credentials that outlast rotation. After a CI compromise, diff trust policies and federated credentials too.
  • Delivery: a required check is only a name until you pin who may post it. GitHub lets anyone with write access set any status, and the same stealer carries code to post passing statuses under a repo's required check names. Set the expected source app on every required check, through org rulesets.
  • One Agent to Hundreds: skills and context files are written for one model, so teams now measure and prune them. Google Chrome's web guidance skill is tested with and without, and pruned where models already succeed. Geoffrey Huntley reconsiders his at every major model drop. Re-run each skill against no skill at each model upgrade.
  • Across the lab: long lists of dated examples were rewritten as patterns with one or two examples each, several claims were narrowed to what their sources say, and a handful of facts were corrected (Terraform and OpenTofu feature split, pstack PR ownership, METR study figures).
  • Smaller: Apache httpd's critical mod_http2 bug, reported by Anthropic's scanner and then by Google researchers, joins the found-twice line (Security); Terminal-Bench 4.1 re-graded after the cheating audit and about 1.16% of trials changed score (Did the Agent Do It Right?); MCP spec releases move to March and September, next 2027-03-30 (Engineering for the Next Agent); Anthropic's measurement that one shared agent beats one agent per user on shared resources, AWS Emulator's adversarial review gate, the Grok Bot team's 11,000 PRs in a month, Jules read-only since 11 Nov, and Spotify's 20,000-line script attributed to its Maven updater (One Agent to Hundreds).
11 Nov 2026
  • One Agent to Hundreds: agent policy is moving off the laptop. Vendors now ship one policy an admin writes that every client enforces: Claude Code managed settings, Kiro's Enterprise Management preview (10 Nov), and VS Code 1.146 (11 Nov) deprecating the local harness that skipped managed policies. For each agent tool, find the client that skips the policy.
  • One Agent to Hundreds: small high-trust teams are dropping the pull request. Mitchell Hashimoto's Superlogical pushes to main with machine review before the push and human plus machine review after, as Amp and Geoffrey Huntley do. Its last gate is a 15-minute release countdown anyone can pause.
  • Security: management planes are the target, and the fix can be to switch one off. N-able took its hosted RMM offline until a hotfix after 33 flaws were published with exploit code, and Vates reported a Xen Orchestra login bypass under active exploitation that leaves no log (10 Nov). Keep these consoles off the internet and rehearse running without them.
  • Engineering for the Next Agent: a gated model can go on sale in weeks. Google gave Gemini 4 Carbon to cyber defenders on 28 Oct and sold it to all paying developers on 10 Nov, keeping only the cyber version behind a program. Re-check model access at each release.
  • Observability: the Collector's batch processor is deprecated (11 Nov). Batching moves into each exporter's sending queue, on by default from v0.171.0 (planned February 2027), and the processor goes in v0.177.0 (planned May 2027). Take it out of fleet configs before then.
  • Smaller: KEV count updated to 1,779, and of some 95,000 CVEs assigned this year 217 reached KEV (Security); Railway's final incident report replaces the preliminary one (One Agent to Hundreds); GenAI metric names corrected, with model-call latency in gen_ai.client.inference.duration and tool calls in gen_ai.execute_tool.duration (Taming Cardinality, Observability); Gemini 4 Argon guide link repointed (Agentic Engineering, Did the Agent Do It Right?).
10 Nov 2026
  • Engineering for the Next Agent: the newest frontier model is again split into one you can buy and one you can't. Anthropic launched Claude Fable 5.2 on 9 Nov, and Mythos 5.2 goes only to organizations in its verification programs. Plan roadmaps on models your teams can call.
  • Engineering for the Next Agent: a cheaper token is not a cheaper task. Fable 5.2 costs 20% less per token than 5.1, but Anthropic's Addy Osmani says a task costs roughly the same and SemiAnalysis measured it 31% dearer, because the model writes far more tests. Budget and compare models per task.
  • One Agent to Hundreds: what a thousand agents need. Anthropic ran one lead and 999 helpers for 28.7 hours. One shared machine gave out at about 100 agents, so each got its own VM with no network, and they coordinated only through a SQL database and Git, with a classifier checking every command.
  • Agentic Engineering: ask rules no longer gate everything in Claude Code. Since 2.1.321, mods Claude writes turn on without asking in auto and bypass modes and their tool calls skip ask rules. Deny rules and organization policy still apply, so put what must never happen in a deny rule.
  • Security: a vendor's cross-account role is standing access until you delete it. An attacker with credentials from Qubole's AWS account assumed customers' unused integration roles, and the External ID stopped none of it (Wiz and Sentra, 9 Nov). Inventory third-party trust and delete what isn't used.
  • Smaller: Claude Code 2.1.321 fixed a read-only Bash command that ran outside the sandbox and an MCP OAuth secret leak, and narrowed the account-email check (Agentic Engineering); KEV count updated to 1,773, sshole added to KEV with a three-day deadline, and valid npm provenance on the malicious bee-js release joins the update-path line (Security); Fable 5.2 fast mode and GitHub's new Git storage in private preview (One Agent to Hundreds).
