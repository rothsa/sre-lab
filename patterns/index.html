    One Pattern, Three Languages

    Everyday SRE tasks (parsing logs, calling APIs, cleaning up cloud resources, querying Kubernetes and Prometheus, checking a fleet, writing an exporter) done in Python, Go and Ruby. The point is the contrast: how each language structures the same job, what that buys you, and what it costs. Step through each diagram with the buttons or your arrow keys, then use the 30-second answer, the gotchas and the quiz to make it stick.

    Every chapter starts with the no-code option, because often jq, kubectl or an existing exporter is the right answer. The code uses the libraries the industry already uses, never hand-rolled versions. Sources are the official docs for each language and library.

    Diagrams, code and wording by Sally Roth. Based on the Python, Go and Ruby documentation.
