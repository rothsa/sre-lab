    One Pattern, Three Languages

    The same reliability patterns in Python, Go and Ruby, side by side, with a diagram of what the pattern does and the traps each language sets. Step through each diagram with the buttons or your arrow keys, then use the 30-second answer, the gotchas and the quiz to make it stick.

    Code uses each language's standard library where it can, and is written to read clearly in an interview rather than to be clever. Sources are each language's official documentation.

    Diagrams, code and wording by Sally Roth. Based on the Python, Go and Ruby documentation.
