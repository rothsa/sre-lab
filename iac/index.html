    Infrastructure as Code

    How to run infrastructure as code across hundreds of teams: state layout as blast-radius policy, shared modules and environments, one gate for every change, drift routed to owners, safety rails and testing. One team's mechanics are the worked example. Step through each diagram with the buttons or your arrow keys, then read the short summary, the gotchas and the questions to think through.

    Examples use Terraform and OpenTofu, with Pulumi, CDK and Crossplane where they differ. Facts come from official documentation; each chapter links to its sources. For what changed in Terraform itself, see Terraform, Five Years On.

    Diagrams and wording by Sally Roth. Sources are linked in each chapter; real-world examples come from The Incident Files.
