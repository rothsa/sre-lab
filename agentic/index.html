    Agentic Engineering, Drawn

    How software gets built when much of the code is written by agents: the agent loop, context, verification-first workflows, orchestrating many agents in parallel, reviewing their output, keeping them safe, using them in operations, and what changes when a whole organization works this way. Step through each diagram with the buttons or your arrow keys, then use the 30-second answer, the gotchas and the quiz to make it stick.

    Grounded first in Lauren Tan's pstack workflow (published in Cursor's plugins repository), then in vendor engineering guides, security guidance and research on AI-assisted development. Each chapter links to its sources.

    Diagrams and wording by Sally Roth. Sources are linked in each chapter; real-world examples come from The Incident Files.
