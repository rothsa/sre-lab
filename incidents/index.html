How well does each do?

Fifteen test questions, phrased the way an on-call engineer might type them, each with the postmortem a good search should find. The honest result: on a small corpus like this the two methods tie more often than you'd expect, because a rare term (DRUPS, PGAudit) stands out to both. They miss different questions, though, so combining their rankings (hybrid search, using reciprocal rank fusion) puts the right answer highest. And some questions beat every method: if a detail isn't in the text, no search can find it.

Summaries were written for this demo from each company's public postmortem; follow the links to read the originals. Postmortems found through danluu/post-mortems. Model: all-MiniLM-L6-v2 via Transformers.js.
