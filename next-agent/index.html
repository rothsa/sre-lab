    Engineering for the Next Agent

    Agent engineering builds on itself. Skills, instruction files, tools and evals written for last year's model still work with this year's, and often work better. Prompt workarounds and step-by-step scaffolding get deleted. The model you build for today is usually overtaken within weeks, so this explainer is about engineering for the agent that is coming: what to invest in, what to keep thin, how to read the capability trends without overtrusting them, and how to upgrade without breaking production.

    Step through each diagram with the buttons or your arrow keys, then read the short summary, the gotchas and the questions to think through. Every number is dated and linked to the lab, vendor or researcher that published it; forecasts are shown with their caveats.

    Diagrams and wording by Sally Roth. Sources are linked in each chapter; real-world examples come from The Incident Files. Companion explainers: Engineering on an Exponential and Agentic Engineering.
